# Python for Beginners

Hi! I'm Muhammad Ali Abid, a BS Artificial Intelligence student building my programming foundations and working toward AI/ML engineering.

This repository contains small Python exercises as I learn. The goal is to practice core programming concepts before moving on to data science and machine learning.

## What's included

- `examples/hello_world.py` — first Python program
- `examples/calculator.py` — a simple four-operation calculator
- `examples/student_marks.py` — calculates a student's average and result

## How to run

1. Install Python 3 from https://www.python.org/downloads/
2. Download or clone this repository.
3. Open a terminal in the repository folder and run a file, for example:

   ```bash
   python examples/hello_world.py
   ```

   Depending on your setup, you may need to use `python3` instead of `python`.
